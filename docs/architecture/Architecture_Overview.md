Architecture

- Layer 1: Presentation/UI

- Flutter app with platform-native UX

- Browser extensions for autofill and password saving

- Layer 2: Application Services

- Authentication service

- Database service

- Search and indexing service

- Sync orchestration

- Clipboard and session management

- Layer 3: Security Core

- Rust library for KDBX parsing, cryptography, and key derivation

- KDBX 3.x and 4.x compatibility

- Protected stream decrypt/encrypt logic

- Layer 4: Storage & Platform

- Local file storage

- Secure secret storage per platform

- Cloud sync adapters

- Native biometrics
